# South Africa Business Risk Desk

This is the first working foundation of the app.

## Included

- South African flag-inspired colour scheme
- National risk rating
- Thirty-day risk timeline
- Interactive Leaflet map
- City-level risk markers
- Incident and disruption filters
- National and city news dropdown
- Business Conversation Brief
- Responsive mobile layout
- JSON-fed architecture

## Important

All current information is labelled demo data. It must not be presented as live intelligence.

## Run locally

Opening `index.html` directly may prevent the browser from loading the JSON file.

From the project folder, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## GitHub Pages

Upload the complete project to a GitHub repository and enable GitHub Pages from the main branch.

## Agreed build sequence

1. Reliable intelligence collection
2. Transparent risk scoring
3. Core dashboard
4. Geographic risk map
5. Route-risk system
6. Conversation intelligence
7. Personalisation and professional release

The next development stage is the automated collection engine. The map should not receive street-level risk scoring until the underlying geographic evidence is reliable.
